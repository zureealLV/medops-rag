## 导入

```powershell
$env:PYTHONUTF8 = "1"
.\.venv\Scripts\python.exe -m scripts.import_chinese_official
```

导入器执行以下门禁：

1. 只接受目录版本 `1` 和 `zh-CN`；
2. 只允许 `www.nhc.gov.cn`、`xzfg.moj.gov.cn`、`www.gov.cn`、
   `udid.nmpa.gov.cn` 的 HTTPS URL，跳转后再次检查；
3. 单文件最多 25 MB，总计最多 100 MB，目录最多 50 项；
4. 验证 `%PDF-` 文件头和目录中固定的 SHA-256；
5. 禁用网络 PDF 的 OCR，使用配置上限且绝不超过 300 页；
6. Unicode NFKC 与空白归一化后，按中文标点/段落边界切片；
7. 相同哈希直接跳过；同标题或同 URL 出现不同哈希则拒绝，需要人工审查后显式升级。

因此，目录来源变更不会被静默覆盖。第二次导入使用已验证缓存并跳过已有文档。

## 边界

- “官方发布”描述的是来源身份，不等于资料可被任意再许可或重新分发；所以仓库不捆绑原文件。
- 食养指南不能替代诊断、用药和个体治疗；法规/标准检索不能替代专业合规意见。
- 固定哈希用于可复现与变更检测，不代表本项目对原文件版权作出授权判断。
- 8 例冻结评测只能证明当前演示问题的回答、引用、拒答和延迟门禁，不代表临床正确性验证。

# Beta.1 Query Transformation Benchmark

## Decision

Keep `query_transform=none` as the automatic default. Rewrite tied the baseline on Hit@1, multi-query was
slightly worse and twice as slow, and deterministic template-HyDE materially damaged ranking quality.

The runtime still exposes all transforms for explicit experiments. Automatic HyDE requires
`HYDE_AUTO_ENABLED=true` and a policy match; the shipped default is false.

## Setup

- frozen `v2_retrieval_documents.jsonl`: 20 documents;
- frozen `v2_retrieval_cases.jsonl`: 120 answerable questions used here;
- FastEmbed 0.7.4;
- `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`;
- BM25 + MiniLM rank fusion for each transformed query;
- multi-query applies a second rank fusion across the original and rewritten rankings;
- cached model load and document indexing are excluded.

Both dataset SHA-256 values match the earlier Beta.1 report.

## Results

| Transform | Hit@1 | MRR@5 | nDCG@5 | Mean | p95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| None | 0.9917 | 0.9944 | 0.9958 | 67.233 ms | 85.291 ms |
| Rewrite | 0.9917 | 0.9958 | 0.9969 | 58.140 ms | 70.809 ms |
| Multi-query | 0.9833 | 0.9917 | 0.9938 | 125.985 ms | 157.610 ms |
| Template HyDE | 0.7833 | 0.8875 | 0.9168 | 112.298 ms | 128.067 ms |

HyDE was especially weak on `choice` and `distractor` cases (both 0.65 Hit@1). Generic runbook language
diluted the discriminating incident/action terms. Rewrite moved one miss from rank 3 to rank 2 but did not
increase Hit@1, so the simpler unchanged query retains the default role.

## Reproduction

```powershell
$env:PYTHONUTF8 = "1"
.\.venv\Scripts\python.exe .\evals\benchmark_query_transforms.py
```

Raw rankings metrics and dataset hashes are committed in
`reports/query-transform-benchmark-v2-beta1.json`.

## Limits

- the corpus is synthetic and has one relevant document per answerable query;
- the HyDE passage is generated by a deterministic template, not an LLM;
- rewrite latency being lower than no-transform is runtime variance, not a speed claim;
- no-transform remains the default because no alternative improved the primary Hit@1 metric.

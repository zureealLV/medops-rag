# Java reading note

The earlier learning plan reserved this directory for a Spring Boot comparison. It is intentionally excluded from MedOps RAG V1: the released application uses one Python/FastAPI stack and does not claim a runnable Java service.

Concept mapping: FastAPI Router ≈ Spring Controller, service module ≈ Service, Pydantic model ≈ request/response DTO. No Java artifact is required to run, test or evaluate V1.
